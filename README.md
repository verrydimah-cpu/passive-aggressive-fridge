A single-line passive-aggressive note from a smart fridge to its owner, written to `/output/entry.txt`. Dry, petty and specific: the fridge has started charging the 12-day-expired yogurt rent, because at this point the yogurt is more committed to living there than the owner is.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
